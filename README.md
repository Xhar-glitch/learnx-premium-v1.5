# LearnX Premium v5

## GitHub Pages
Upload the **entire folder** to the repository root. Keep all media inside `assets/`.

Required media:
- `assets/intro.mp4` — intro 9:16.
- `assets/dashboard-base.mp4` — dashboard base video.
- `assets/fingerprint-reference.png` — blue fingerprint reference.

The web app intentionally keeps videos as media files instead of converting them into JavaScript/base64. This gives the browser a better chance to stream them smoothly on Android and GitHub Pages.
